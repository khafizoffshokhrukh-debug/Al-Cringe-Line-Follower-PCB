## 🚀 About the Project

This is a **custom-designed PCB** developed for our **Al Cringe Line Follower Robot**.

The PCB was designed, ordered for manufacturing, received and **hand-assembled**. It was created specifically to make the robot's electronics more compact, organized and practical.

---

## ✨ Main Features

- 🧠 **ESP32-WROOM** — main controller
- ⚙️ **TB6612FNG** — motor driver
- 🔋 **LM2596** — step-down converter
- 🔊 **Active buzzer**
- 🔘 **Push buttons**
- ⏻ **Power switch**
- 🔋 **XT60 battery connector**
- ⚙️ Dedicated motor soldering points
- 👁️ **6 line-sensor soldering points**
- 🔩 **4 mounting holes** for attaching the PCB to the robot
- 📐 Complete schematic and PCB layout
- 🧊 3D PCB model
- 📋 Component/BOM list
- 📦 Manufacturing files
- 🛠️ Real assembled PCB
